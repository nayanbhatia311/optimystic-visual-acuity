# Contributing

Thanks for helping improve Optimystic.

1. Fork the repository and create a focused branch.
2. Build the `VisualAcuity` scheme in an iPhone simulator.
3. Keep personal data, signing certificates, provisioning profiles, build output, and exported test results out of commits.
4. Open a pull request explaining the user-visible change and how it was tested.

For security or privacy concerns, avoid attaching real patient information to a public issue. Share only synthetic reproduction data.
